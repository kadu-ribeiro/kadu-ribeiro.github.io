rclone Google Drive client

This page exists to satisfy the Google OAuth consent screen requirement for a personal, single-user OAuth client.

The application is an unmodified installation of rclone, an open source command line program to manage files on cloud storage. It runs on a single personal Linux machine and is used by its owner to mount that owner's own Google Drive as a local filesystem.

It is not distributed, not offered as a service, and has no users other than the account owner.
