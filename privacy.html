Privacy policy

Last updated: 20 September 2026

Scope

This policy covers the personal OAuth client used by an installation of rclone on a single Linux machine. The client has exactly one user: the owner of the Google Account it connects to.

What is accessed

The client requests the Google Drive scope in order to read, create, modify and delete files in the account owner's own Google Drive. This access is used solely to present that Drive as a mounted filesystem on the owner's computer.

What is stored

The OAuth refresh token is stored in the rclone configuration file on the owner's computer, readable only by the owner's operating system user account. File contents are cached on a local disk on that same machine to make reads and writes faster.

What is shared

Nothing. No data is transmitted to any third party, any server operated by the author, or any analytics service. Network traffic goes only between the owner's computer and Google's own APIs.

Retention and deletion

The local cache can be deleted at any time by removing the cache directory. Access can be revoked at any time from the Google Account permissions page at myaccount.google.com/permissions, which immediately invalidates the stored token.

Contact

Questions about this policy can be sent to the email address registered as the support contact on the OAuth consent screen for this client.
